# 综艺剪辑导演：先剪故事，再做美术

真实专业后期工作流强调粗剪、精剪、花字包装、音效混音逐步衔接；剪辑不是全程贴字或高频转场。

## 八个剪辑手法及其设计搭档

| 剪辑 | 使用场景 | 配合的花字/美术 | 禁忌 |
|---|---|---|---|
| 反应镜头 | 旁观者真实表情 | 人物心理小字 | 拿无关反应误导观众 |
| 定格 | 意外或尴尬表情 | 人物卡/后期补刀 | 盖脸或定格过长 |
| 慢放 | 关键动作值得重看 | 轨迹、局部放大、拟声字 | 大量无意义慢镜 |
| 重复回放 | 细节需要二次解释 | 第二遍加入视觉分析 | 反复堆回放 |
| 快切 | 情况逐渐失控 | 字幕密度递增 | 为快而快 |
| 空白静音 | 尴尬与反差 | 极简短花字或无花字 | 静音损害对话理解 |
| 声先画后 | 悬念、反转 | 先听声，包袱揭晓才上字 | 文字剧透 |
| 景别推进 | 重要表情或细节 | 微型表情贴片 | 糊脸或不真实视觉误导 |

## 时间线策划
- 从真实片段识别：铺垫 setup → 期待 expectation → 事件/揭晓 payoff → 他人反应 reaction → 余味 aftermath。
- 每个镜头输出：源素材起止、成片起止、剪辑意图、要不要花字、文字内容、出现时机、图层位置、音效和安全区。
- 剪辑先于花字设计，但两者共同审稿；文字要与动作因果和喜剧节奏绑定。
- 反应镜头、人物动机和先后关系必须基于实际素材验证。
- 禁止每隔固定秒数切一刀或强制每个镜头上花字。

## FFmpeg 可运行执行器
`scripts/variety_edit.py` 基于人工填写的 JSON 时间线执行 `normal`、`speed`、`freeze`、`replay`、PNG overlay；输入和素材路径可相对工程根目录。它不负责 AI 自动发现笑点，也不直接生成剪映工程。

### 实际使用
```bash
python scripts/variety_edit.py examples/clip-plan.example.json --out outputs/variety_edit.mp4
```
