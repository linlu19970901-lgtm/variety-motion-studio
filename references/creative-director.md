# 综艺创意导演

## 逐镜头推演
对每个镜头填写：
- 事实：说了什么、做了什么、谁看到了什么。
- 情绪：尴尬、得意、怀疑、开心等；不要过度推断。
- 喜剧机制：反差、预言、补刀、误解、类比、拟人、视角错位、回扣。
- 额外信息：后期文案是否带来了新内容，而非复述原话。
- 设计隐喻：哪些图形或字形可让观众在瞬间看懂笑点。
- 节奏：铺垫 / 反转 / 观众消化 / 退场。
- 安全区：哪里不应遮挡。

## 三案竞争
A：以环境或材质发想。
B：以人物关系或荒诞角色发想。
C：以字义、字形、排版发想。
可以更换方向，但三案必须有不同的创意机制。

## 拒绝标准
- “好好笑”“震惊了”等无内容的普适花字。
- 只换颜色、外描边或弹跳方向的伪三方案。
- 在包袱揭晓前剧透。
- 盖住人物关键表情、手势或关键信息。
- 让一段平静真实的情绪被过度包装。
