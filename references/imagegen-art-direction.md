# AI 生图驱动的综艺视觉美术流程（V0.3 设计方向）

> **必须遵守：** 本项目不是将现成文字放在预设几何框上的工具。固定矩形、爆炸框、渐变描边不能作为主要创意。参考节目的精神而非复制其资产。

## 先判断是否能调用图像生成模型
- 运行该 Skill 的 Agent 必须检查当前环境是否提供真正的图像生成或图像编辑能力。
- **有生图工具时**：用生图工具生成主视觉、插画材质、文字融合构图的视觉草案；每个方案单独调用，至少两种创意机制，不能只改颜色。生图工具由宿主环境提供，Skill 本身不包含 API 密钥或模型绑定。
- **无生图工具时**：提供可直接复制到图像生成工具的详细提示词，以及图层拆分、字形排版与剪映制作指导。必须明确写出“尚未生成图像”，不得以 Pillow 几何图冒充专业美术设计。
- 已有脚本 `scripts/make_caption.py`、`scripts/art_caption.py` 仅能做低保真排版、标注和交付格式测试。不得默认作为终版花字生成器，也不得将这种输出包装成综艺正片级成品。

## 1 发现“这句话独有的东西”
记录：
- 原片内容：人物做什么、说什么、场景里有什么、观众刚看到什么。
- 情绪关系：谁得意、谁尴尬、是谁在吐槽谁。
- 创意钩子：歧义、比喻、动作、物件、地域、人物特征或反差。
- 文字是否必要：删掉它会不会更有戏？
- **禁止抽象空词**：“震惊了”“这下好玩了”作为默认文案。

## 2 创意导演输出三案
每案描述：
- 后期文案（尽量短）
- 核心视觉隐喻（具体物件/空间/动作）
- 字形与材料的关系（字本身如何参与创意）
- 插画与背景的关系（为什么是这个图形，不是随机装饰）
- 文字位置、主体占比、画面安全区
- 动效设计（入场/停留/反应/退场）
- 为什么与视频片段内容独有地关联
三案需分别采用不同创意路径，例如人物拟物、环境衍生、语义字形。不得只改字体、色彩、底板。

## 3 静态关键帧：先生图，再做文字精修
- 首先生成只包含美术元素或简单可控文字的高质量画面，重点观察质感、笔触、图形隐喻、构图。
- **中文文字精度**：AI 生图容易产生错字、乱码、字形变形。不得把错误文字当成终稿。优先采用“无字美术底层 + 单独可编辑中文文字层”的混合流程；遇到创意字形与画面高度融合时，仍需人工或程序准确覆字、遮罩合成与确认。
- 对角色相关插画：使用原始人物画面作定位参考，不臆造无依据的真实人物外貌。
- 不能只用几何底板、对齐文本和装饰线条完成作品。

## 4 生成提示词结构
请根据用户素材填写以下完整描述，不要直接把括号里的占位符丢给生图模型：

**概念**：[一句话表达真正的视觉隐喻]
**节目世界观**：[温暖手作 / 荒诞喜剧 / 激进观念视觉——自行提炼，不照抄现有节目]
**中文内容**：[精确文案]；如采用无字分层设计请指定“留出清晰的文字安全区域”
**文字造型**：[字体笔触、结构、大小关系、字形如何与物件联系]
**插画主体**：[具体物件、动作、姿态、线条、材质、与文案的关系]
**构图**：[文本视线引导、动态方向、人物遮挡区、画面占比]
**色彩**：[主辅色不超过需要的数量，与节目及镜头的关系]
**输出要求**：专业综艺后期视觉包装，清晰边缘、画面整体设计，避免贴纸堆砌、通用漫画气泡、廉价 PPT 渐变、随机光效、无意义爆炸框。
**分层交付**：美术底层 PNG、准确中文文字透明 PNG、预览合成图、可选动效分镜。

## 5 设计总监审核（未通过则回到创意阶段）
- 如果把文字换成任何别的句子仍成立，则 **创意不及格**。
- 如果换一档综艺还能原样套用，则 **节目气质未建立**。
- 如果静态帧像 PPT 或商用通用模板，则 **重做**。
- 如果中文出现错字或乱码，则 **不可交付**。
- 如果插画和人物、场景、文案没有关系，则 **删掉并重构**。
- 如果强动效掩盖包袱或真实表演，则 **减弱或移除**。
- 生图模型输出必须由使用者/Agent 查看实际结果再审，不能根据提示词假定成品很好看。

## 6 剪映小白交付
优先按以下顺序：
1. 一张合成预览 PNG，说明设计与人物画面如何搭配；
2. 一张美术插画层（透明 PNG，如技术允许）；
3. 一张准确的中文文字层（透明 PNG）；
4. 可选装饰层和音效；
5. 导入剪映：原视频底层、插画层居中、文字层在最上，调时间和位置。
如果背景必须抠除且模型无法输出 alpha，明确提示在剪映抠像或另行使用透明化工具，并检查边缘质量。

## 7 原创案例演示（概念而非已生成图片）
原片“说好只散步，结果要跳舞”，人物随即慌乱：
- A 环境衍生：地面散步路线在画面上转出舞步轨迹，字像跟着脚印被带动。
- B 人物荒诞：在旁边画一张精细的“步数异常警报”，指针从散步冲到蹦迪，但不能像通用仪表 PPT，要有属于本档节目的人物视觉语言。
- C 语义字体：“散步”逐渐被步频挤成“蹦迪”，先设计高质量创意字形，再编排短动画。
三案造型、材质和动机不同；不得简单更换模板色。
