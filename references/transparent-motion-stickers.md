# 透明动效贴片规范 · v0.4

## 最新用户审美验证（2026-11-19）
第一轮整屏拼贴、海报式大字卡虽视觉热闹，但**不适合直接当综艺正片贴片**。第二轮完整田园纸张/报告板/字形海报仍有封面感。第三轮以独立透明底的 6 帧小型动效贴片进行试验，用户明确反馈“好多了”。故本规范为**优先级最高的创作交付规则**，不把既往 PPT 风格当成合格样式。

## 默认交付规格：真正的叠加素材
- **默认只有贴片自身**：透明 RGBA 画布，画布外和贴片周围是真实透明 alpha，不能是棋盘格、纯黑、纯白、绿色或经过压平的背景。
- **不是完整封面**：不自动添加场景人物照片、整屏拼贴、全画幅渐变、完整海报背景。
- 视觉主体围绕关键语义设计，例如“散步变开跳”需要脚印→舞步、轻松步频→跳跃姿态的**实质变化**，不是仅仅颜色更亮、整体缩放。
- 允许中文标题结合画面，准确字形是硬要求。错误字形重做或另做可编辑文字层。
- 主体的动态改变应该清楚：元素入场 → 语义转变 → 重点词强调 → 轻巧收尾；不要整段无差别抖动。
- 同一组帧必须严格维持图形身份、文字内容、材质、颜色及比例；可改变的是运动和表情。
- 提供透明底静态首帧 PNG、透明动态版本、分帧 PNG 和一张真实视频叠加预览。预览图可以含人物和场景，但**不得把预览图当作贴片素材**。
- 对真实视频优先按人物安全区布局：局部小贴片而非遮挡屏幕中心。

## 生图模型动画帧生成（如宿主支持 GIF 动画）
先以静态关键帧检查美术，再请求**6 或 8 帧同尺寸格子精灵表**，帧之间逐步变化；每格完整容纳相同贴片、没有跨格的物件、没有额外边框、帧号和说明。整表画布是透明背景。在静态预览中看起来的黑色可能是透明底的显示方式，不可据此认定透明，必须用 alpha 检测。
若生图平台直接返回 GIF：保留动画 GIF 并检查透明通道。GIF 是二值透明且会出现边缘锯齿，优先 APNG 或 Alpha 视频。

## 动效的两个层次
- 内容运动：脚印走到一半变舞步、进度条从缓慢飙升、提示单从折叠变展开、文字被语义力量挤压。这是创意核心。
- 动画修饰：轻微弹入、错位、旋转、描边闪动。这只是辅助，不能替代内容运动。

## 视频编辑器导入优先级
1. **最通用**：静态透明 PNG，使用剪映自带入场/出场动画。
2. **逐帧 PNG**：素材分帧按时间顺序导入，可控但操作较多；要求详细时间码。
3. **GIF/APNG**：文件可以真实保存透明动效，但**不同版本剪映导入效果可能不同**，先测试。
4. **Alpha 视频**：VP9-alpha WebM / ProRes 4444 MOV 只在实际编辑器环境兼容测试通过后推荐；不要把普通 H.264 MP4 称作透明视频。
5. **绿幕兜底**：必要时提供纯绿背景 MP4 供色度抠像，需检查边缘溢色和细节损伤。

## 质量关卡
- alpha 实测：非透明区域与边缘正确，画布空白区域 alpha=0，不是黑色像素。
- 真实叠加检查：在浅色、深色、繁忙视频画面各试一次。
- 动画一致性：前后帧角色/中文/图形不乱变，没有多手或乱码。
- 可读性：缩到手机尺寸仍能读。
- 画面融合：不会遮脸，不遮关键信息，动作不剧透。
- 叙事必要性：贴片出现有准确笑点，退出及时。
- 交付真实性：若只生成 GIF，不宣称生成了可透明导入剪映的 MOV。

## 推荐 Prompt 约束
“生成一枚可用于中文综艺正片叠加的**独立透明 RGBA 动效贴片**。只出现花字、相关的小型原创插画和辅助图形，不要全画幅背景，不要海报，不要人物摄影，不要节目封面。中文准确写 [具体文案]。基于 [真实场景] 的独特行为，把 [物件动作] 发展为 [语义视觉转折]。动画分为 [N] 帧等尺寸格子，同一贴片完整位于各格，形体/笔触/颜色/文字严格统一，主要运动从 [状态A] 演变为 [状态B]，每格背景透明且无边框，适合后续合成透明动画。避免 PPT 式底板、随机爆炸框、与内容无关的图形。”
