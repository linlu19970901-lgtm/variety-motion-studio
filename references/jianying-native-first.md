# 剪映优先制作架构 · V0.5

## 设计目标
让零基础用户获得真正可用于节目正片的原创透明贴片、综艺节奏和操作方案。不是让剪映代替 AI 美术，也不是所有素材都提前渲染为 GIF。**有剪映原生功能就优先交付原生动画参数；复杂逐帧动画才预渲染。**

## 功能证据与兼容说明
- 国内剪映：官方账号演示过画中画、蒙版、关键帧及智能抠图；操作入口随电脑/手机和版本变化。参考 https://www.bilibili.com/video/BV1UF411x7ri?p=7
- CapCut Desktop 官方关键帧说明 https://www.capcut.com/help/keyframes-in-capcut-pc 和 https://www.capcut.com/resource/how-to-add-keyframes-in-capcut
- CapCut 官方变速曲线与编辑工具 https://www.capcut.com/resource/how-to-use-capcut
- CapCut 桌面自动字幕 https://www.capcut.com/resource/ai-generation-and-full-timeline-editing-in-capcut-desktop
**不要把国际版 CapCut 的每一个界面/功能直接认定为中国剪映某版本可用。** 若目标平台未确认，在交付中标记“需在用户版本确认”，并给可行替代方案。

## 动效路线自动选择（必须执行）
1. **Level 1 / 新手低操作**：一张真正透明 PNG + 剪映入场/出场预设。适合轻微反应、短吐槽、信息提示；只需导入、定位、调整时长。
2. **Level 2 / 推荐默认**：创意插画 PNG + 准确中文字 PNG + 可选物件 PNG；配 2–5 个位置、缩放、透明度或旋转关键帧、持续时间、视觉层级。适合脚印变舞步、情绪角色弹出、词义强调。把复杂视觉留给生图，简单运动交给剪映。
3. **Level 3 / 复杂动画**：角色真实姿态逐帧、中文复杂字形变形、流体/烟雾/定向遮挡等需外部渲染；生成 PNG 序列 + 可验证的透明动画格式，附剪映导入替代方案。
原则：按目标画面质量与用户操作复杂度取最低合格档。**不能把“动画 GIF 可生成”当成“剪映能直接透明导入”。**

## 五种可以复用的剪映综艺剪辑配方
### A. 人物自信→翻车｜定格补刀
- 对话铺垫保持自然原声。
- 结果揭晓后定格或轻微放大人物反应，不提前剧透。
- 透明花字小幅缩放弹入；原声保留，极短错误提示音可选。
- 反应镜头结束就退场；如果没有确切表情素材，不凭空编造反应镜头。

### B. 散步→开跳｜分层语义动画
- 人物运动视频保持在主轨。
- 放入 3 个独立透明 PNG 层：准确中文文字、脚印、跳跃轨迹。
- 先出现“散步”的步印；经过语义反转点才加入跳跃轨迹与“开跳”突出层。
- 使用位置/缩放关键帧，让脚印沿画面下缘移动，强调词跳起再落下。
- 控制整体区域，不遮挡人的腿和舞步动作。

### C. 空气突然安静｜留白与静音
- 音效和背景音乐短暂衰减，重要人物对白不消音。
- 先留 0.2–0.5 秒空白，再出现极简小字或无字。
- 字体用简洁透明 PNG，轻淡入；避免大面积图卡遮挡表情。
- 剪辑反应结束立即恢复现场环境声。

### D. 错误答案｜复看与注释
- 关键动作或表情先原速完整出现。
- 随后才短慢放或重放，第二次在问题发生的位置加一枚透明注释贴片。
- 如果用缩放，避免因裁切损害关键信息；不要制造有误导性的反应顺序。
- 音效与花字出场同步，不盖过对话。

### E. 密室提示｜蒙版逐步揭晓
- 静态美术底层 + 文字层并列到上层轨道。
- 若剪映版本支持对该类素材使用蒙版/关键帧，沿线索方向逐步揭晓；否则用预先渲染的逐帧 PNG。
- 不在剧情正式公布前暴露谜底；保护场景里原有解谜信息。
- 对复杂透视/遮挡使用外部合成，剪映只进行最终叠加。

## 统一时间线清单
每条贴片都应有：
`source_time`, `timeline_time`, `purpose`, `text_exact`, `assets`, `level`, `layers`, `keyframes`, `sfx`, `safe_area`, `fallback`, `verified_in_target_version`。
输出参考 `templates/jianying-recipe.example.json`。

## 默认关键帧建议（可调，非行业标准）
- 轻弹入：0ms 88%/透明 0 → 90ms 108%/透明100 → 170ms 100%。
- 微吐槽：0ms 96%/透明0 → 130ms 100%/透明100；保持后快速淡出。
- 角色踩踏：连续 3–5 帧空间位置变化，优先沿真实脚步方向。
- 大爆点仅在确有铺垫后使用，切忌全片同一个弹跳曲线。
这些是**制作起点，不是已在全部剪映版本实测的操作参数**。

## 自动审稿要点
- 人物有无被遮挡？
- 原生操作是否简单于渲染复杂视频？
- 文字是否准确、手机尺寸能读清？
- 贴片是否与具体台词/动作有独特联系？
- 动效是否增加笑点，而非通用弹跳？
- 关键帧是否能由剪映当前版本支持？
- 最终必须实看成片，避免 PTT/PPT 字卡和不必要铺满画面。
